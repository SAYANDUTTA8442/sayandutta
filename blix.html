01 — COGNITIVE STACK

Four systems, one runtime.

Blix treats cognition as a coordinated stack rather than a single model call — each layer reads and writes the same memory graph.

Curiosity

Scans belief state for low confidence, contradictions, sparse evidence, and unknown domains — surfaces exploration targets ranked by expected information gain. No RL, no self-play.

Metacognition

Tracks its own capability, selects strategy from a self-model, and evolves those strategies over time via the capability tracker and strategy selector.

Planning

Beam search with a learned critic and a replanner — plans are evaluated, scored, and revised mid-execution rather than committed to blindly.

Causal

Explicit cause → effect edges in the graph, separate from correlation — queried directly when reasoning about "why," not inferred at generation time.

02 — HGSHM

One pipeline, twelve tiers of compression.

Hybrid Graph-based Semantic Hierarchical Memory. Raw events compress upward automatically — nothing is deleted, every tier keeps a SUMMARISES edge back to its sources.

Raw Episode Conversation Session Daily Weekly Monthly Project Concept Principle Knowledge World Model

Retrieval is an 11-factor fusion, not a single similarity score — semantic match, vector distance, graph expansion, temporal recency, and importance are ranked together, then passed through hierarchy resolution and contradiction detection before reaching the reasoning layer.

Query → Semantic · Vector · Graph Expansion · Temporal → Importance Ranking · Hierarchy · Contradictions · Causal → MemoryContext → Reasoning. Every stage is inspectable — nothing is a hidden embedding lookup.

quickstart.py 
from pathlib import Path
from memory.hybrid.hgshm import HGSHM

h = HGSHM(Path("memory/"))
h.believe("Deployment failed due to timeouts", confidence=0.85)
h.observe_cause("peak_traffic", "timeout_errors")
h.add_principle("Monitor timeouts before deploy windows")

# retrieval fuses 11 ranking factors
ctx = h.recall("deployment failure root cause", top_k=10)
print(ctx.get_text_summary())

04 — RESEARCH CONTRIBUTION

Memory no longer stores only knowledge — it now stores policy.

ADMA — Adaptive Dual Memory Architecture. Retrieval weights and planner configuration aren't fixed constants; they're bandit arms, selected by Thompson sampling and updated from observed outcomes. The prompt compiler assembles itself from whichever policy is currently winning.
